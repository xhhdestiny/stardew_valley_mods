# BetterSkullCave — 星露谷物语 Mod

一个改善**骷髅洞穴**体验的 SMAPI 模组，包含三个可配置功能：  
BetterSkullCave is a SMAPI mod that improves the Skull Cavern experience in Stardew Valley. It includes three configurable features. 

1. **层数文字变色**：把骷髅洞穴左上角「当前层数」从原版紫色（`Color(110,43,255)`，投影仪下看不清）改成可配置的浅色。  
First, it changes the current floor number in the upper-left corner from the vanilla purple color (Color(110,43,255)), which can be hard to read on a projector, to a configurable lighter color. 
2. **宝藏替换**（整合自 NoHatTreasureSkull）：把骷髅洞穴宝藏房里的**帽子**替换成可配置的物品（机器 / 炸弹 / 种子 / 药品 / 树苗）。  
Second, it replaces hats found in Skull Cavern treasure rooms with configurable items such as machines, bombs, seeds, medicine, or saplings. This feature is integrated from NoHatTreasureSkull. 
3. **整百层不跳洞**：跳洞下落时不会越过整百层（100/200/300…），保证能拿到整百层的奖励宝箱。  
Third, it prevents you from skipping hundred-floor milestones when falling through holes: floors 100, 200, 300, and so on will not be passed over, ensuring you can still get the reward chest on those floors. 

以上所有开关都能通过 **Generic Mod Config Menu** 在游戏内实时调节。  
All switches can be adjusted in-game in real time through Generic Mod Config Menu.
